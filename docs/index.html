Anonymity-focused API allowing GymBuddy users to submit, track, and manage incident and maintenance reports.

Read the status of a single report

GymBuddy retrieves report progress and history using the unique case code.

path Parameters
caseCode
required
string
Example: SB-88219

The unique case code returned when the report was created.

Responses

Local development server

http://localhost:3001/reports/{caseCode}

  • 404

path Parameters
caseCode
required
string

The unique case code returned when the report was created.

Request Body schema: application/json
required
status
required
string
